# Images

Put your own collection images and category backgrounds in this folder.

The first version of the site deliberately uses CSS-generated atmosphere so it works
without any external assets.

Later you can add, for example:

- `gundam/freedom.jpg`
- `digimon/dukemon.jpg`
- `mecha/prototype-01.jpg`
- `fantasy/fate-example.jpg`

Then reference them from `data/items.json` like:

```json
"image": "assets/images/gundam/freedom.jpg"
```

The reference images you showed in chat were used as *style direction* rather than
copied into this project.
